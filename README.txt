Khulshi Hills Masjid Accounts - GitHub Pages upload

Upload every file and folder in this folder to the root of the repository:
  index.html
  manifest.webmanifest
  sw.js
  icons/   (folder with 4 PNG files)

Then in GitHub: Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
The site address will be: https://<your-user>.github.io/<repository-name>/
